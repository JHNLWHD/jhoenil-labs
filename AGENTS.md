# Repository context

Jhoenil Labs is Jhoenil Wahid's personal portfolio and consulting website. It presents his work across web and mobile development, DevOps, technical leadership, AI-powered solutions, and data engineering. The site is a React and TypeScript single-page application built with Vite, Tailwind CSS, and shadcn/ui, and deployed on Netlify.

Read [`README.md`](README.md) for the full project overview, feature list, technology stack, local development instructions, and deployment details.
